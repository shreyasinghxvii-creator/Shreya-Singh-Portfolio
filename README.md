A professional portfolio showcasing my journey as an Information Technology student transitioning into UI/UX Design and Full-Stack Development. This project focuses on building clean, efficient interfaces and exploring intelligent automation.

## 🚀 Key Project: Compario
**Compario** is an AI-powered price comparison platform developed during my professional engagement with Infosys (Oct-Dec 2025).

* **Objective**: Solve the problem of manual price searching across major platforms like Amazon, Flipkart, Croma, and Snapdeal.
* **Core Logic**: Uses Tesseract OCR to extract text from product images and Google Gemini AI to refine noisy data for accurate search queries.
* **Architecture**: Built with a Flask backend, Selenium for automated data fetching, and a React frontend.
